# Gravitton

Shared files of the [Gravitton](https://github.com/gravitton) organization.

- `profile/`: the organization profile shown on its GitHub page.
- `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` and `.github/`'s issue and pull request
  templates: the community files every repository inherits.
- `.github/workflows/go.yml`: the reusable workflow every Go library calls for its CI.
- `templates/images/`: what each library's `docs/images` is made from, the logo templates and
  the files every figure generator shares.
